# 🚀 CP-31 Sheet — 800 Rating

This repository contains my solutions to **800-rated problems from the CP-31 Sheet by TLE Eliminators**, a structured roadmap for improving competitive programming and problem-solving skills.

## 📌 What is CP-31?

CP-31 is a curated competitive programming sheet designed to help programmers practice problems progressively, strengthen their fundamentals, and become more confident at solving Codeforces problems.

This repository focuses on the **800-rated difficulty level**, the starting point of the sheet.

## 🎯 Why 800-Rated Problems?

Although these problems are beginner-friendly, they help build the foundation required for more challenging competitive programming problems.

Practicing them helps develop:
- **Logical thinking:** Learn to break problems into smaller, manageable steps.
- **Problem-solving skills:** Identify key observations and simple mathematical patterns.
- **Implementation skills:** Convert ideas into correct and efficient code.
- **Edge-case handling:** Understand constraints and avoid common mistakes.
- **Consistency and confidence:** Build a strong foundation before moving to higher ratings.

## 🛠️ What I'm Learning

- Basic algorithms and implementation
- Arrays, strings, and sorting
- Basic mathematics and greedy thinking
- Conditional logic and simulation
- Time and space complexity analysis
- Recognizing patterns and handling edge cases

*These are learning areas, not an exhaustive list of topics covered by every problem.*

## 📂 Repository Structure

Each problem is organized in its own folder, making solutions easy to navigate, review, and improve as the sheet progresses.

## 🌱 My Goal

My goal is to focus on understanding the **logic behind each problem**, rather than simply memorizing solutions. By consistently practicing 800-rated problems, I aim to strengthen my fundamentals and gradually progress toward higher difficulty levels.

**Solve. Understand. Improve. Repeat.** 💪
